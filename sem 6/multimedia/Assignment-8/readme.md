Exercise 3: Flying bird

Aim - To make flying bird using macromedia flash 8.

Procedure
1. Create a new document.
2. Draw the body of the bird in layer 1 using oval tool or you can use other image.
3. Draw the wings of the bird in layer 2 using oval tool or you can use other image and give them a colour.
4. Insert keyframe in layer 2
5. Using free transform tool shrink the wings of the bird.
6. Insert keyframe and using free transform tool enlarge the wings of the bird.
7. The procedure is done for several times repeatedly.
8. Layer 1 is inserted for time frame equal to layer 2.
9. Press ctrl+enter to view the animation done.

Result - A flying bird is created using macromedia flash 8
